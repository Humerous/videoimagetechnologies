# Video Image Technologies — Website V2

This folder is the workspace for the new full Video Image Technologies website.

## Purpose

The new website will expand the current landing page into a structured company website covering:

- Company overview and positioning
- Media and data systems architecture
- Ingest, process, manage, store, protect and handover workflows
- Services, capabilities and selected project experience
- Project enquiries and contact information
- Official social and company updates

## Deployment safety

The production coming-soon page remains at the repository root in `/index.html`.

Files created inside `/website-v2/` will not replace the live landing page until the new website is reviewed and deliberately promoted to production.

## Suggested structure

```text
website-v2/
├── index.html
├── pages/
├── assets/
│   ├── images/
│   ├── icons/
│   └── fonts/
├── css/
├── js/
└── docs/
```

Brand-approved files should be used from the VIT active brand package rather than copied from the legacy site without review.
