# Video Image Technologies

**Clear Vision. Reliable Systems.**

Video Image Technologies designs and supports media data systems for secure handling, reliable backup, structured archive, and clean workflow handover.

## Current production state

The current production site is a branded VIT holding page.

Official website: https://www.videoimagetechnologies.co.za/

The holding page is live and includes a direct VIT contact action. Its footer displays the company year range dynamically from 2016 to the current year.

The full website remains planned under `/website-v2/`.

## Deployment

Pushes to `main` deploy automatically through the existing Vercel project.
